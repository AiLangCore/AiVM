# AiVM Design Notes

Status: non-normative.

This directory contains runtime design notes, proposals, rationale, experiments,
and accepted architecture decisions for AiVM.

Design documents do not define AiLang language semantics. They also do not define
AiVM runtime contracts unless the contract is moved into `../SPEC/`.

## Filename Classes

- `*.feature-<name>.md` - active feature design or proposal.
- `*.decision.md` - accepted architectural decision record.
- `*.note.md` - shared developer note or rationale.
- `*.experiment.md` - exploratory runtime work.

Every design document should clearly state whether it is proposed, accepted, or
historical.
